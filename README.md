# CAR - Caeli's Automatic Rice 

A rice of Arch Linux as I would customize an installation. It will install apps and configs to customize the look and feel according to mytastes.

---

## Hyprland (Window Manager)
*A modern Wayland compositor featuring dynamic tiling, animations, and advanced window management. It’s used to create a fast, visually polished, and keyboard-centric desktop environment.*

| Modifier  | Use                |
|-----------|--------------------|
| `<SUPER>` | Main Modifier      |
| `<ALT>`   | Secondary Modifier |

---

## Terminal 

### Alacritty (Terminal Emulator)
*A GPU-accelerated terminal emulator focused on performance. It’s used for fast terminal workflows with minimal latency.*

### Zsh | Z-shell
*An advanced Unix shell used as an interactive command-line interpreter. It’s used for its powerful tab completion, scripting features, and customization through themes and plugins, making terminal workflows faster and more efficient.*

---

## Neovim (Editor)
*A highly configurable, terminal-based text editor focused on speed and extensibility. It’s used for coding and text editing with powerful plugins, LSP support, and keyboard-driven workflows*

| Modifier  | Use        |
|-----------|------------|
| `<Space>` | Leader key |

---

## File Management

### Yazi
*A fast, terminal-based file manager with image and video previews. It’s used for efficient file navigation and management directly from the terminal.*

### Nautilus
*GNOME’s graphical file manager. It’s used when a traditional, mouse-driven file browsing experience is preferred*

---

## Misc.

### Wofi (Application Launcher)
*A lightweight application launcher for Wayland. It’s used to quickly launch apps, run commands, and switch tasks using a searchable menu.*

### Waybar (Status Bar)
*A customizable status bar for Wayland compositors. It’s used to display system information like workspaces, battery, network, and time.*
