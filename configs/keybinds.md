# Keybinds Cheat Sheet

---

## 🪟 Hyprland

### Applications
- **Super + Enter** → Open terminal  
- **Super + Space** → App launcher  
- **Alt + F** → File manager  

### Compositor / Session
- **Super + Alt + Q** → Exit Hyprland  
- **Alt + Shift + H** → Reload Hyprland  
- **Alt + Shift + W** → Reload Waybar  

### Focus Windows
- **Super + {h/j/k/l}** → Focus window  
- **Super + {←/↓/↑/→}** → Focus window  

### Move Windows
- **Super + Shift + {h/j/k/l}** → Move window  
- **Super + Shift + {←/↓/↑/→}** → Move window  
- **Super + Mouse Left** → Drag window  

### Resize Windows
- **Alt + Mouse Left** → Resize window  

### Layout / State
- **Super + V** → Toggle floating  
- **Super + Shift + F** → Fullscreen  
- **Super + S** → Toggle split (dwindle)  

### Screenshots
- **Alt + C** → Screenshot area → clipboard  
- **Super + S** → Screenshot screen → file  
- **Super + Shift + S** → Screenshot area → file  

### Workspaces
- **Super + {1–9}** → Switch workspace  
- **Super + 0** → Workspace 10  
- **Super + Shift + {1–9}** → Move window to workspace  
- **Super + Shift + 0** → Move window to workspace 10  

### Window Management
- **Super + Shift + Q** → Kill active window  

### Media
- **XF86AudioRaiseVolume** → Volume +5%  
- **XF86AudioLowerVolume** → Volume −5%  
- **XF86AudioMute** → Toggle mute  
- **XF86AudioMicMute** → Toggle mic mute  
- **XF86AudioPlay / Pause** → Play / pause  
- **XF86AudioNext / Prev** → Next / previous  

### Brightness
- **XF86MonBrightnessUp** → Brightness +5%  
- **XF86MonBrightnessDown** → Brightness −5%

## ✏️ Neovim

### Tabs
- **Leader + t n** → New tab  
- **Leader + t c** → Close tab  

### Search (Telescope)
- **Leader + f f** → Find files  
- **Leader + f g** → Live grep  
- **Leader + f b** → Buffers  
- **Leader + f h** → Help  

### Git
- **Leader + g c** → Commits  
- **Leader + g b** → Branches  
- **Leader + g s** → Status  
- **Leader + g d o / g d c** → Diffview open / close  
- **Leader + g h** → File history  

### LSP – Navigation
- **g d / g D** → Definition / declaration  
- **g r** → References  
- **g i** → Implementation  

### LSP – Actions
- **H** → Hover docs  
- **Leader + l r** → Rename symbol  
- **Leader + l a** → Code action  

### Mason
- **Leader + m o** → Open Mason  
- **Leader + m i / m d** → Install / uninstall LSP  
- **Leader + m u** → Update LSPs  

### Lazy (Plugins)
- **Leader + l z o** → Open Lazy  
- **Leader + l z s / c / x** → Sync / check / clean  
- **Leader + l z l / d / h** → Logs / debug / help

## 📁 Yazi

### Navigation
- **{j/k} or {↓/↑}** → Next / previous file  
- **{h/l} or {←/→}** → Parent / enter directory  
- **gg / G** → Top / bottom  
- **H / L** → Back / forward directory  

### Scrolling
- **Ctrl + {d/u}** → Half page down / up  
- **Ctrl + {f/b}** → Full page down / up  

### Selection
- **Space** → Toggle selection  
- **v / V** → Visual select / unset  
- **Ctrl + a** → Select all  
- **Ctrl + r** → Invert selection  

### File Operations
- **Enter / o** → Open  
- **O / Shift + Enter** → Open interactively  
- **y / x** → Copy / cut  
- **p / P** → Paste / force paste  
- **d / D** → Trash / delete permanently  
- **a** → Create file/dir  
- **r** → Rename  
- **.** → Toggle hidden files  

### Search / Jump
- **s / S** → Search name / content  
- **z / Z** → FZF / Zoxide jump  
- **/ / ?** → Find next / previous  

### Sorting
- **, {a/m/s/e/n/r}** → Sort (alpha / mtime / size / ext / natural / random)  
- **Shift** → Reverse sort  

### Tabs
- **t** → New tab  
- **{1–9}** → Switch tab  
- **[ / ]** → Previous / next tab  
- **{ / }** → Swap tabs  

### Goto
- **g h / g c / g d** → Home / ~/.config / ~/Downloads  
- **g Space** → Interactive jump  

### Misc
- **; / :** → Shell command (non-blocking / blocking)  
- **w** → Task manager  
- **~ / F1** → Help  
- **q / Q** → Quit
